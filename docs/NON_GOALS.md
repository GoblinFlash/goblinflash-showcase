# Non-Goals

This repository is intentionally narrow.

## Not a Support Channel

This repository does not provide device support, firmware repair support, unlock support, or dump analysis.

## Not an Operational Guide

This repository does not provide:

- flashing commands
- write-path details
- exploit chains
- bypass procedures
- device-specific offsets
- vendor-specific operational guidance
- patch recipes

## Not a Source Release

This repository does not include GoblinFlash core source, private firmware material, generated experiment artifacts, private cases, or sibling project source.

## Not an Authorization Layer

No document in this repository grants authority to modify firmware. Evidence summaries, architecture notes, or governance descriptions are not write authorization.

## Not a Public Intake Queue

Issues are intentionally off. Discussions may be enabled later only for controlled architecture and research discussion.
