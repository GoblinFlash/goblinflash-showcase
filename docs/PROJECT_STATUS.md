# Project Status

This repository is a private docs-only skeleton for a future GoblinFlash public showcase.

## Current State

- local repository skeleton created
- no remote publication
- no GitHub Pages
- no GitHub Actions
- no issue templates
- no support workflow
- no production source disclosure

## Intended Audience

The intended audience is technical reviewers who need to understand the project safety posture, evidence-review model, and governance discipline without receiving operational firmware modification instructions.

## Before Public Release

Before public release, the repository needs a separate review for:

- accidental private detail disclosure
- unsafe operational wording
- support-policy clarity
- discussion policy
- license and public-contact decisions
- final redaction pass

## Current Policy

Keep private until the operator explicitly approves public publication.
