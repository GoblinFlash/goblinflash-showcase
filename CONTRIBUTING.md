# Contributing

GoblinFlash Showcase is a documentation-only public safety and evidence-review showcase.

This repository does not accept contributions that include or request:

- firmware dumps
- BIOS or SPI dump material
- device-specific patching
- unlock instructions
- offsets or variable write guidance
- exploit chains
- bypass recipes
- flashing instructions
- write-path details
- private firmware cases
- generated experiment artifacts
- GoblinFlash core source code
- sibling project source code

Pull requests in these categories may be closed without review.

Acceptable contributions are limited to public-safe documentation improvements, wording corrections, safety-boundary clarifications, and high-level process notes.

Evidence is not authorization.  
Parser output is a witness, not an oracle.  
AI assistance is not engineering authority.  
Read-only analysis is the default.
