# Security Policy

This repository is a documentation-only showcase. It is not a support channel and does not provide firmware modification assistance.

## Supported Scope

Security discussion is limited to the public documentation boundary:

- wording that could imply unsafe authority
- accidental disclosure of private project detail
- process gaps in the public-facing safety model
- documentation that could be misread as operational guidance

## Out of Scope

The following requests are out of scope:

- device-specific support
- firmware dump review
- BIOS dump review
- SPI dump review
- unlock requests
- flashing or write-path requests
- exploit development or bypass guidance
- private case discussion
- requests to publish source code not intentionally included here

## Reporting

While this repository is private, report concerns directly to the project operator through the existing private channel. Do not attach firmware dumps, private logs, device identifiers, or customer material.

If this repository becomes public later, a separate disclosure process may be documented before any public security contact is advertised.
